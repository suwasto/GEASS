# Build a focused evidence demo before nationwide surveillance

The first GEASS build covers one region and budget year selected after a small SIRUP, LPSE, and SSH evidence sample passes validation. The user chose a focused hackathon demonstration over implementing the entire PRD immediately; Sukoharjo is a candidate, not a verified commitment. This puts a reproducible investigation ahead of the PRD's unverified 5,000-row target and nationwide coverage.

Nationwide ingestion, anonymous uploads, and continuous monitoring are deferred. Real observations and synthetic test fixtures must be visibly distinguished; a fixture cannot substantiate a real-world allegation.
