# Human review controls publication

The user chose human review before publication, public access to approved evidence-backed risk signals, and authentication for reviewer actions and uploads. Prosecutor/defense model debate supplies counterarguments; it cannot approve its own output or establish criminal liability.

Draft assessments, raw identity observations, and source documents remain private. Publication exposes a reviewed projection with evidence references and limitations; later evidence or analysis changes require a new review. Store the reviewer identity, reviewed version, timestamp, and decision, and support withdrawal. Authentication proves identity; a server-side reviewer allowlist authorizes publication. Use Google identity authentication for the demo reviewer surface; do not let authenticated outsiders self-enroll as reviewers.
