# Use SQL evidence edges and downloadable draft dossiers first

The user accepted SQL evidence edges and Markdown draft dossiers first, deferring GQL reservations and enrichment. Represent observed vendor/tender relationships in BigQuery tables and return a bounded graph through parameterized SQL. BigQuery Graph exists, but GQL reservation requirements make it an unnecessary initial dependency; keep graph storage compatible with later exploration. Do not introduce Spanner, a separate graph database, or an MCP server solely for this demo.

Co-bidding, bid ratios, and observed address overlap are evidence edges, not ownership merges or confirmed collusion. Use namespaced source vendor identities until stronger identifiers justify a reviewed merge; masked NPWP prefixes and geocoding are insufficient by themselves. Show unavailable participants or evaluation details explicitly.

Generate downloadable Markdown PPID drafts and audit briefs with source references first. Defer PDF formatting, AHU enrichment, geocoding, live retail benchmarks, and citizen uploads. No email delivery or automatic filing is part of the demo; legally phrased templates need a source and review gate before public use.
